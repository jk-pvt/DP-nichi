# Design Patterns Catalog

A minimalist desktop app built with **C# (.NET 8)** and **Avalonia UI** that makes learning design patterns simple and interactive.

Instead of heavy theory and confusing jargon, every pattern is explained using simple everyday analogies, a problem-vs-solution breakdown, an interactive live simulator, and clean C# source code you can explore and copy.



### Run Locally

```bash
# Clone the repository
git clone https://github.com/DarkTechPirate/DP-nichi.git
cd DP-nichi

# Run the app
dotnet run
```
